# Pro Image 100：独立可达性与单位核对

2026-10-31。新增实现为 `spk_material_fit --spectral --certify-bounds`，可运行的 v2 诊断，不是仅有设计。旧 `--spectral` v1 和默认 CDF 报告格式/字节不变。

## 不依赖优化器的证据

给定本次 400–700 nm 截断仪器响应、基底 `b(l)`、染料 `d(l,k)` 和层量 `0 <= a(k) <= 8`，有：

`b(l) + sum(a(k)*d(l,k)) >= b(l) + 8*sum(min(d(l,k),0))`。

透射率因此有上界；以非负仪器权重求和后取负 log10，得到每通道密度的必要下界。这是放松每个波长共享 CMY 层量的约束，**不会把可达点错误证明为不可达**；反过来，满足下界并不证明可达。实现使用稳定 log-sum-exp，并以独立 long-double 透射 oracle 的已知正/负染料样本检查界限，未调用反演优化器来构造证书。

| 通道 | 必要下界 D | 低于下界的目标点 | 低于下界超过 0.02 D |
|---|---:|---:|---:|
| R | 0.273504941524 | 25 | **9** |
| G | 0.677050615539 | 0 | 0 |
| B | 0.893145444343 | 0 | 0 |

已证明越过误差门限的 9 行为源索引 0–8，log lux-seconds −3.14 至 −2.98。第一点红目标 0.2467 D，比最低可达红密度低约 0.026805 D。这是当前数据/有界模型的矛盾，不是增加起点或迭代次数能消除的。

原来的数值反演失败为 12/201；另 3 个失败没有被此必要界单独证明，**没有把 12 个数值失败都称为解析不可达证明**。证书仅适用于给定光谱支持、仪器表和层量盒子，不否定真实胶片，更不是标准认证。没有修改原始数据、放宽质量门或覆盖已有 Profile。

## 原厂页核对

检查了 Kodak 作者的 *E-4L, July 1997* 曲线原页（印刷页 3，四页 PDF 的索引 2），不是只读取上游 JSON 的简述。PDF SHA256：

`f2d1a1faa32bbbc96ab4f69ffa5ee7d99f8bc554392dcec42f715fb934d92700`

来源：[Kodak 原厂数据表的历史镜像](https://analogfilm.space/assets/kodak-proimage-100.n3IH3y40.pdf)，另有 [B&H 镜像](https://www.bhphotovideo.com/lit_files/519169.pdf)。本地检查文件为 `build/validation-20261031-ui/kodak-e4l-mirror.pdf`；仅供本地检查，不复制进 Git/应用包。作者/权利仍为 Kodak，公开镜像不构成许可变更。B&H 的终端下载被访问检查拒绝，改用公开镜像；没有绕过检查。用 Poppler 渲染并目视检查了曲线、条件和脚注；渲染器提示 Symbol/ArialUnicode 字体回退，因此没有以该栅格图重新数字化坐标。

- 感光度是以 `erg/cm²` 能量曝光定义的倒数；1 erg/cm² = 0.001 J/m²。
- 感光度测量条件为 1/50 秒、C-41、Status M 高于 D-min 0.2 D。
- 特性曲线横轴是 lux·seconds（日光曝光），不能仅把能量单位换算后直接共用曝光轴。
- 原页仅给代表性涂层曲线，不保证每卷实际一致。基底图和特性曲线也不是一份可任意强制共同暗部的高精度测量表。

v2 对固定胶片源哈希附 `manufacturer_unit_audit`、来源 URL/哈希和单位换算，仍标记 `absolute_exposure_anchor_calibrated=false`。未知输入不自动附 Kodak 的定义。源 JSON 提到 page 4，原厂四页文件的曲线实际在印刷页 3；原字节仍保留，不用静默改文件来掩盖归属差异。

## 没有发布 Profile 的理由与下一步

绝对感光度单位已找回，但完整光谱支持、日光辐射分布/光度匹配、Status M 仪器条件和真实染料层响应仍未共同标定。把低曝光点删掉、把 CMY 放到负数、把基底下调至目标，或直接把三条 Status M 曲线当作本征染料层，都会隐藏而非解决矛盾。

在不篡改材料的约束下，要发布可用 Profile，需要相互一致的基底/染料/曝光数据及独立图像验证。当前可交付的是已运行的反演、证书和完整失败记录；**Pro Image 100 仍未完成注册与 Vulkan/导出回归，不宣称已可选**。如果另做假设性研究模型，应有独立 ID、明确估计/先验与残差，并与原始材料分开，不以“实测完整标定”命名。

最终命令、报告和测试结果随 `UI_RESULTS.md` 记录；工具使用说明在 `windows_UI/material_fit/README.md`。
