# 真实数据采集与分组契约 v1

数据集：`dataset.json`。当前 samples=[]，**EMPTY / NOT VERIFIED**。没有真实测量结果。`sample.template.json` 是表单，不属于样本集，填齐并核实授权前不得导入。

每个样本记录：

- `generation`（Phoenix 200 / Phoenix II）、批次、roll_id、scene_id、ISO、EI、曝光秒数、光圈、相对曝光 EV、场景描述。
- 光源描述/SPD（或显式 unknown+reason），色卡型号、序列号、参考值出处与照明/几何条件。
- C-41 实验室、日期、温度 °C、时间 s、药液、增减感档数；另记药液新鲜度、补充率与控制条情况。
- 原始底片/扫描文件相对路径、每个文件 SHA256；保留原件，派生文件另记父哈希与配方哈希。
- 扫描设备型号/序列号、扫描光源、ICC 文件及哈希、渲染意图、扫描位深/分辨率/软件版本、所有自动校正开关（曝光/WB/对比/饱和/锐化/降颗粒）。
- 来源、权利人、许可全文/链接、授权依据和允许的再分发范围。公开可见不等于获准使用或再分发。

未知测量用 `{"value":null,"reason":"..."}`，不能填入看似合理的数字。底片/扫描/ICC 文件缺失或哈希不符时完整性验证拒绝。JSON 内声称 real-film-paired/authorized 不是可靠性的独立证明；必须人工核对来源、实际底片/场景配对和仪器条件。

训练/验证/测试在任何拟合前冻结。共享 roll_id **或** scene_id 的所有记录须在同一 split；同一底片或扫描的文件哈希也不能跨 split。同场景相邻曝光不能拆开。场景与胶卷关系形成的连通组整体分配；不使用随机逐图划分。ICC 相同不会把整个数据集错误连在一起。

运行 `node validation/phoenix-round4/dataset.cjs validation/phoenix-round4/dataset.json`，空集只报告 EMPTY_NOT_VERIFIED。加 `--require-fit` 会拒绝空集/无独立训练验证/缺证据声明；即使通过完整性门也不会启用拟合，`fitting_enabled` 恒为 false。

采集需包含冲洗后的透明底基、扫描暗参考、中性阶梯、色卡及曝光包围；尽可能记录透射光谱、带宽、波长范围、仪器、测量几何、线性化和不确定度。扫描 RGB、厂家曲线数字化与染料光谱属于不同数据类型。

可靠配对数据到位后另行启用受约束校准，顺序固定：中性/曝光/亮度；底基与有效染料响应；扫描转换与平衡；独立验证集 D50 Lab ΔE00；跨曝光和跨场景稳定性。同时报告灰阶、Y、L*、色相、色度和裁切比例。不以照片 3D LUT 宣称物理参数准确。本轮不含拟合器，也没有伪造参考图。
