# 保留的边界与下一步输入

- **真实物理校准阻塞**：没有具有授权、冲洗/曝光/仪器条件和独立场景/胶卷分组的真实配对数据。Phase 4 未开始；所有真实胶片 ΔE00/灰阶/亮度/色相/色度指标为 null。
- **硬件扫描验证阻塞**：没有扫描器光源与探测器响应的可靠测量。本实现明确为理想化代理，不等同于任何商用扫描器。
- **旧 GUI 实时参数缺口**：已审计真实 EXE/资源/保存状态和只读 UI 选择；原 EXE 无实时 get_params 入口，不能把新实验参数冒称旧进程当前参数。
- **本轮界面/导出范围**：独立原生 Qt 查看器、A/B 与局部放大、预览尺寸 TIFF16/ICC；不是原有编辑器的新默认。监视器校准、原生尺寸和 macOS/Metal 未验收。
- **材料证据缺口**：II 代际曲线归属、Phoenix 实测染料/底基、Gold 代理的物理迁移适用性仍未解决。原始 v1 和所有其他材料保持不变。

有数据后先完成来源/权限、配对和 split 冻结，再做中性曝光与亮度，随后底基/有效染料、扫描转换，最后独立验证和跨曝光/场景稳定性。禁止以照片 3D LUT 或单张照片变好代替物理验证。
