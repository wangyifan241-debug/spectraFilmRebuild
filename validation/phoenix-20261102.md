## Verification

- Full Windows CTest: **40/40 passed**, including native schema/setup,
  Vulkan kernels/C ABI, QML workflow, material library and existing color/output tests.
  This run used the integration workspace, which also contained separate pending
  negative-scan/automatic-inversion work. It is not proof that those changes are
  part of the Phoenix-only PR. Isolated PR-tree validation is recorded separately.
- New `spk_qt_phoenix`: **3,281 checks**, synthetic gray/24 color patches,
  ±2/±6 EV, numerical/response ordering, nonfolded DIR axes, separate generation
  responses, physical grain and halation controls/bypasses, TIFF/PNG8/PNG16/JPEG,
  equal-resolution preview/export agreement, per-photo recipe persistence and
  existing Portra restoration. Both saved/reopened previews were identical.
- Offline research gate: **3,254 checks**, finite arrays, source CSV/profile
  hashes, monotone response and DIR axes, assumed-instrument fit closure,
  print-calibration identity and preservation of every original filter entry.
- The deliberately injected NaN counterfactual fails; CTest's expected-failure
  gate passes only when it is rejected.
- Before integration, new native regression failed on old resources with
  `Phoenix profile absent`.
- A stricter gray-ramp check exposed full generic DIR coupling folding the new
  high-contrast model's transformed axis. It failed before the material baseline
  scale was reduced to the explicitly estimated 0.15. The original curves were
  retained; final native/offline checks and rendered gray ordering passed.
- Save/reopen initially exposed inherited previous-stock print packs; explicit
  new-stock packs fixed this without changing original database entries.
- Default Endura/TH-KG3 print packs were then calibrated to model midgray via
  the actual Vulkan path. Repeating the final calibration produced identical
  CMY packs and zero quantized log-R/G and log-B/G residuals. This is model
  output calibration, not a physical-film measurement.

The final gate used the standard `windows_UI/build.ps1 -RunTests -Jobs 1`
through the existing ASCII workspace junction to avoid Qt's Unicode path issue.
An earlier parallel compile encountered memory exhaustion; serial build passed.
The full gate is the Windows CTest target, not macOS/Xcode or upstream Python
oracle parity. No external physical-film fixtures were available.
