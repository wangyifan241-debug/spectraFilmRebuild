# SpektraLab Windows · spectraFilmRebuild

[English](README.md)

这是我们维护的 Windows 移植，使用 Qt Quick、C++ 光谱胶片/印相模拟和 Vulkan。
目前仍是测试版，不是全部 macOS 功能对等正式版，也不代表上游官方发布。

**完整代码及开发说明位于
[codex/windows-materials-ui-20261031 分支](https://github.com/wangyifan241-debug/spectraFilmRebuild/tree/codex/windows-materials-ui-20261031)。**
main 仅保留项目入口，不另行维护一份应用代码。

功能、构建、已知限制及安装说明请看
[Windows 版 README](https://github.com/wangyifan241-debug/spectraFilmRebuild/blob/codex/windows-materials-ui-20261031/README.zh-CN.md)。
不要使用标记了 NOT-FOR-DISTRIBUTION 的旧安装包。测试版尚未签名，仍需独立干净电脑验收。

本项目基于 James Qiu 的 SpektraLab 和 Andrea Volpato 的 spektrafilm。
