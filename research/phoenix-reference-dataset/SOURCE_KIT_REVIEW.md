# Supplied-source kit review

User-named directories were absent. Actual files were found at `research/phoenix_reference_fetch_kit/phoenix_reference_fetch/` and `research/phoenix_ii_expansion_kit/`, plus a root expansion CSV. Both READMEs, CSV/JSONL inventories, the PowerShell downloader, Python preview downloader and existing download logs were read. Source-kit scripts/files were not modified or executed against originals.

PowerShell script: public direct URLs, TLS, finite timeout and redirects, no authentication/proxy bypass. However IDs are not constrained as filenames, failed/small destinations can be deleted, format checks do not fully decode all formats, and every non-Phoenix-200 row falls into the II folder. Therefore it is unsuitable for execution over existing originals. Existing 22 files were fully decoded, hashed and copied with exclusive creation; provided files remained unchanged.

Python script: bounded single-page requests, no login or guessed private endpoints, only social previews. It lacks robots checking, structured metadata verification, proper resume and true-original selection. It was not run unchanged. Owned tools honor robots per host, stop on HTTP errors, preserve existing originals, log failures and verify image bytes. A verified canonical Lomography URL was checked after a dead film-scoped URL; its 403 was respected. Gallery-count claims were never treated as acquired photographs.

Two sets of differently sized press samples were visually confirmed as duplicates: Marcus cliffs (prefer 1280px over 800px) and Naeem parasol (prefer 2000px over 800px). SHA256/dHash and source aliases are retained. The two supplied copies of the expansion CSV are fingerprinted in the batch summary, not counted as separate sources. Supplied 22 direct links are individual photos, whereas album/review/group leads remain discovery-only until individually checked.

Published sample images are not necessarily original scans. No unlisted high-resolution endpoint was inferred. Unknown reuse permission remains explicitly unknown; all non-CC supplied/public-page originals are private reference artifacts, not approved for repository distribution or formal fitting. Conservative presentation-border/watermark masks and provisional untagged-sRGB assumptions are recorded for each exploratory statistic. They do not validate scanner colour or intrinsic film response.
