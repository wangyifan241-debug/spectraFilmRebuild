# First exploratory analysis — one reviewed image per stock

Actual statistics: exploratory_statistics.json and exploratory-distributions.png.
Embedded ICC was transformed through LittleCMS to sRGB. The untagged Phoenix II file uses an explicitly recorded exploratory sRGB assumption, not a verified profile. The entire bottom 8% was excluded to avoid its watermark; source bytes remained unchanged. Lab is D65; OKLab and linear luminance are separately recorded.

Indoor mixed-light transit and outdoor architecture/sky differ in content, illumination, author and unknown scanner. Differences cannot identify a film-generation effect. No population signature, formal fitting, semantic-region measurement, grain recovery, halation parameter or accuracy claim is made.
