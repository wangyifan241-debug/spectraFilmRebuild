# SpektraLab Windows · spectraFilmRebuild

[简体中文](README.zh-CN.md)

Our Windows port uses Qt Quick, C++ spectral film/print simulation and Vulkan.
It remains a preview, not a feature-complete or officially endorsed macOS release.

**The application source and full documentation are on
[codex/windows-materials-ui-20261031](https://github.com/wangyifan241-debug/spectraFilmRebuild/tree/codex/windows-materials-ui-20261031).**
This main branch is the project landing page, not a second application checkout.

See the [Windows README](https://github.com/wangyifan241-debug/spectraFilmRebuild/blob/codex/windows-materials-ui-20261031/README.md)
for features, build instructions, limitations and preview installation information.
Do not use an old installer marked NOT-FOR-DISTRIBUTION. Previews are unsigned;
independent clean-recipient-machine testing remains required.
