# 2302 接入与扫描拟合续作（2026-10-31）

本轮基于 `602ec32`，不覆盖上轮材料。用户授权继续 2302 与扫描数据拟合；改动保持两个可区分的成果：运行时电影印片材料，以及不会进入渲染器的离线拟合研究工具。

## 2302

新增 `open_kodak_2302_5m_033`，上游 dev 固定 commit `6cd00c8d4f30b5b550f50f4bbd3753c9f2a48507`，作者 Andrea Volpato / CC BY-SA 4.0。原始 SHA256 `3c04bb2e7701eae97eaaf14100cbf80c8f00dd07db3deda3f14b37ac060ca2be`。原样 JSON、完整许可和逐项变更记录位于 `engine/resources_open/`。

转换器 `material_audit/Convert-Print2302.ps1` 校验源字节哈希，固定 **5 分钟**（原始条件为 2/3.5/5/7/9 分钟），统一切片基底、特性曲线、三子层与 CDF；银通道表示转换沿用前两款的光密度守恒方法，不移动曝光/波长轴。全部条件原样存档，不添加连续显影插值。

它保留 `support=film`、`stage=printing`、负向感光响应，是从负片曝光得到正像的电影印片胶片，不是拍摄正片或普通相纸。产品身份可参见 [Kodak 官方 2302/3302 页面](https://www.kodak.com/en/motion/product/post/print-films/black-and-white-2302-3302/)。使用上游的明确条件，不把搜索到的另一处理时间偷偷写进数据。

Qt 选择黑白负片后，在“印相材料 · 相纸 / 印片”或材料库选择 2302。新增版本及其命名空间导入副本用 C=M=Y=0 的无滤片桌面策略。Ilford 保留 Y=68；**未知旧自定义银盐材料也保留原有兼容策略**，避免泛化修复改变旧照片。没有改测量数据来补偿滤片，也没改核心物理或 C ABI。材料管理详情保留打印阶段和载体类型，旧自定义注册记录在重扫时从实际 Profile 补读载体字段。

仍保留现有放大机照明与曝光归一化、扫描/印相效果默认；不是特定电影光学印片机、颗粒或投影条件的独立标定。该边界同时写在材料质量字段与 NOTICE。

- 首次数据复制早于新 Profile 生成，测试因缺夹具失败；重新运行资源同步，没有用 checkout 回退掩盖问题。
- 首轮参数断言误读成嵌套 `enlarger`，但 C ABI 返回平铺 wire；已修正并增加字段存在检查。随后**刻意恢复旧的全部黑白 Y=68 策略**，测试在正确读到 wire 后失败（`materials-2302-flat-red-test.log`，25.05 秒）。再恢复仅 2302 无滤片策略后通过。
- 首轮绿色 `spk_qt_open_material` 为 **9365 项 / 28.55 秒**：三份新材料转换守恒、Vulkan 默认/确定性、旧 Portra 前后不变、三编码器、历史保存、自定义 2302 导入和切换时的实际滤片参数。后来又补了未知旧自定义银盐材料的 Y=68 兼容门，需以最终整合结果为准。

`PreviewHost::resolved_params_json` 只读现有 `spk_get_params`，用于观察实际引擎参数，不新增一套参数实现或控制面。QML 工作流追加实际 2302 选择按钮、黑白印片路径和“不冒充 Multigrade 相纸”的文字检查，原生窗口抓图为 `material-2302.png`。

## 扫描数据拟合：已做到哪一步

新增 C++/Qt Core 工具 `app/spk_material_fit.exe`，仅离线拟合，不链接进入交互渲染器，也不引入运行时 Python。详见 `material_fit/README.md`。

首个固定真实输入为 Pro Image 100：OwlMightyCh / film-scan-calibration，commit `8d03a0e0c111625b8a88fb8647a35d95b491249d`，CC BY 4.0。原始曲线、感光度、代理染料及许可证原样保存于 `engine/resources_research/scan/`，SHA256 和来源见 NOTICE；不自动部署为运行材料。

工具对 R/G/B **Status M 仪器密度（含基底）**拟合有界三 Gaussian CDF + offset。201 个采样中训练 161、留出 40；首轮留出 RMSE R/G/B 为 **0.0008713 / 0.0005389 / 0.0009952 D**，最大绝对误差 **0.0016487 / 0.0009840 / 0.0018911 D**。报告包含逐点预测、残差、留出索引、完整输入哈希、算法版本、阈值和阻塞门；不改原始轴/数据。

这些是相关数字化点上的一维拟合误差，**不是实拍颜色准确度，也不是仪器密度到染料层的标定结果**。报告 `profile_ready=false` 且格式不是 Profile，管理器明确拒绝导入。仍需：光谱前向积分/层量分离、缺测尾部和代理染料不确定性处理、曝光/感光度锚点、独立实拍与 Vulkan 回归。没有把曲线拟合成功说成新胶片物理模型完成。
