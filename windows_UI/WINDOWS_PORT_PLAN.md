# SpektraLab Windows 完整移植计划

更新日期：2026-10-30（北京时间）。这是后续 Windows 移植的执行与验收清单。

## 目标与范围

目标不是“Windows 上有一个相似窗口”，而是对齐当前 macOS 版已开放功能的实际行为、编辑状态和输出结果。

对照代码基线：`fd891c6bc5eb350387602deb5c1ef9b6dcdab948`。上游更新时先登记差异，不能悄悄改变本计划的验收范围。详细历史见 [Windows/Mac 审计](WINDOWS_MAC_AUDIT_2026-10-28.md)。

- 胶片与相纸使用共用材料数据和渲染逻辑；不靠修改测量数据、关闭效果或增加空控件伪装完成。
- Windows 用 Qt/Vulkan 实现 Mac 功能；窗口装饰、系统文件对话框等使用 Windows 原生形式，不要求逐像素复制 AppKit。
- 包括编辑器、文件库、导出、设置，以及 Mac 已开放的 CLI/MCP 入口；不能只完成主画布就宣布全部移植。
- Mac 当前关闭的局部蒙版、Tone Mask、Enlarger 独立面板不作为本轮默认开放项目。保留兼容性，不擅自打开；其他面板已使用的印相参数不因此排除。
- 平台能力限制必须明确记录。例如 HDR 需支持的显示器；LibRaw 不支持的 RAW 压缩格式不能声称已支持。

## 当前起点

已有实现和局部验证：RAW 导入、基础胶片/相纸模拟、CineStill 800T、四款黑白胶片及银盐配对、裁切/旋转/翻转/拉直、逐图设置、撤销/重做、基本批量操作、sRGB 文件输出、画面直方图、第一版显影后基础调节。

上述不是完整 Mac 对齐：本轮 Qt 已改为 ProPhoto 显影后处理，并补上曲线、四分区色彩平衡、暗角和解码原图/分屏；仍需 Mac 对照与真实交互验收。原尺寸导出已分离，但画布仍是 3400 像素编辑预览。大图及分阶段验证见 [本轮记录](VALIDATION_2026-10-30.md)。

最近构建：`build/qt-20261030-color`，2026-10-30 13:52，Qt 6.11.3 / MinGW 13.1。完整构建与 CTest 20/20（含自有 DNG 的 QML 完整回归）通过；真实 Sony 照片库/编辑流程通过。失败记录、截图和限制见本轮验证记录；这仍不是 Mac 完整套件或物理显示器验收。

## 执行顺序与里程碑

状态：待开始 → 进行中 → 已实现待验收 → 已验收；缺少必要条件则记“待外部验证”。只有满足验收标准并登记证据，才可标记已验收。

时间列是粗略的有效开发工作量，不是日历交付承诺，不代表聊天结束后会自动后台开发。各阶段可能因共用改造而重叠，也可能因显存或色彩问题扩大。P1、P2 完成后重新估算剩余总量，不先承诺一个没有依据的完成日期。

## 每阶段的执行规则

1. 开始前列出本阶段对应的 Mac 源文件、Windows 缺口、受影响状态与输出表面。
2. 按可独立验证的小块实现。修复回归时先展示失败测试，再验证修复后通过；先跑最窄测试，阶段集成时跑完整 Windows CTest。
3. 新参数同时接入逐图状态、保存/迁移、撤销/重做、同步、重置、单张与批量导出；不允许只接滑块。
4. 任何新增画面表面都检查裁切加四分之一转的对应关系。胶片条按 Mac 显示完整照片与裁切外遮罩，不能误当作导航图。
5. 引擎改动保留严格数学、缓冲区保护和节点 flush；不以降低精度、改材料曲线、删除拒绝分支替代实现。
6. 完成一个可演示阶段后更新本表和验收记录，再提供可启动版本。不会因“编译成功”或“按钮出现”勾选完成。
7. 若遇到阻塞，登记具体原因与不受影响的下一项；不反复询问一般实现选择。需要新权限、重大范围变化或外部设备时才请求用户介入。

## 验证与外部条件

| 验证层 | 用途 | 当前边界 |
|---|---|---|
| C++/Qt/Vulkan 单元及合成输入测试 | 算法、边界、存储、控制器和文件像素 | 已有测试，但不能覆盖所有真实相机/大图 |
| 真实 RAW 全流程与压力测试 | 解码、显存、切图、批量、尺寸与稳定性 | 需准备真实样本；测试只操作隔离副本和自己的输出目录 |
| Windows 实际窗口 | 原生对话框、点击、快捷键、重绘与卡顿 | 离屏 QML 捕获不能替代这一层 |
| Mac/Windows 对照 | 同一输入、相同参数、各输出阶段和最终画面 | 此 Windows 环境不能运行 Mac；需要 Mac 输出/日志或可运行的参考环境，缺失时标“待外部验证” |
| 显示器与分发环境 | ICC/HDR、驱动与无 SDK 机器启动 | 依赖对应硬件/干净环境，不能用当前开发机通过代替 |

Mac 自身已记录的缺陷（例如直方图裁切统计）要单列差异说明，不为了视觉一致故意复制错误。数值对照沿用已有适用门槛；RAW 解码器差异、工作空间差异与渲染误差分别报告，不能混成一个“看起来差不多”。

### 本轮后续（安装器与首版拟合面板）

- 安装器为用户级 NSIS 3.12，原 13:52 稳定二进制及对应源码快照冻结在 `build/installer-20261030-preview-1`；1701 文件哈希、中文加空格路径隔离启动、拒绝覆盖及保留额外用户文件的卸载已通过。不是干净机器验收，也不是完整 Mac 移植。
