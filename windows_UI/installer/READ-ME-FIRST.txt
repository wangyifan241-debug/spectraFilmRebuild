SpektraLab Windows 测试版 / Windows Preview
==========================================

这是移植中的测试版，不是功能完整的 macOS 对等正式版。

启动：开始菜单 > SpektraLab Preview > SpektraLab。
不需要安装 Qt、Python 或开发工具。请保留安装目录内所有文件。
需要 Windows x64、支持 Vulkan 的显卡及可用驱动。
目前仅在本开发机验证；其他显卡、显示器、干净系统仍待验证。
安装包尚未签名，Windows 可能显示未知发布者；请先确认来源和 SHA256。
不要关闭系统安全保护来安装不可信文件。

已接入：RAW 导入、胶片/相纸、裁切和几何、逐图保存、撤销、
批量导出、ProPhoto 工作链、显影后曲线/色彩平衡/暗角、原图和分屏。
已接入场景拟合、胶片边框、日期、半格双拼，以及版本化材料库管理。
包含 37 份运行时材料；Pro Image 100 尚未通过数据质量门，不在材料列表中。
电影材料旁显示 CINE；普通胶片不因名称或商标而自动归为电影材料。
显影后普通数值滑块拖动查看数值，松开后应用完整精度。
画布仍是最长边 3400 像素编辑预览；导出另行渲染原尺寸。
未完成：HDR、多输出色域、完整实时 GPU 显影后处理及全部 Mac
数值/真实窗口对照。不要据此认为全部 Mac 功能已移植。
请先用照片副本测试，不要将此测试版作为唯一生产工具。

安装只影响当前 Windows 用户，不要求管理员权限，不修改 RAW 文件关联。
更新测试版：先退出程序并卸载旧测试版，再安装到空目录。
卸载保留照片和应用数据目录中的 Edits 编辑记录。
同一个源文件不要同时在多个程序实例中编辑。
